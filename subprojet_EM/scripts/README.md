# Scripts du sous-projet Hardy-Weinberg et EM 

Vous trouverez un script R nommé `analyse_HW_EM.R` qui contient toutes les commandes ainsi que des explications. 

En résumé, ce script permet de : 

- calculer les fréquences alléliques à partir du principe de Hardy-Weinberg. 
- calculer les fréquences alléliques à partir de l'algorithme EM. 
- créer un tableau en format csv dans `resultats/` contenant les fréquences alléliques selon la méthode.

## Packages nécessaires

Aucun package supplémentaire à télécharger pour ce script.
