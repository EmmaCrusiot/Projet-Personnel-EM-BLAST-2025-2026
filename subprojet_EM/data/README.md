# Données pour Hardy-Weinberg et EM 

Les données sont le nombre d'individus dans une population de chats sauvages de phénotype [TaM] ou [Tab]. Elles proviennent de l'article scientifique cité en source. 

Les données ont été obtenues en décembre 2025.
